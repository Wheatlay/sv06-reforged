Status screen (proposal)

Drawn pixel for pixel on the real 128×64 grid with real U8glib fonts and the stock icons (trimmed to fit). Temperatures on top, with targets underneath only while heating; two times with the night-mode moon between them; the progress bar with the percentage inside; the file name at the bottom. Messages replace the file name while printing and "Ready" while idle.

Time left comes from the M73 lines OrcaSlicer already writes.
