    How the counting works
    
During every print the printer counts the filament the extruder actually pushes and subtracts it from the loaded
      spool when the print ends. "Grams left" of 0 means "not set": no warnings for that spool. Before a print, the printer warns
      when the file needs more than is left, or when the file is for a different filament than the loaded spool.

    
Tip: in your slicer's filament profile, add M1100 A2 (with your slot number) to the start G-code. Printing with
      that profile then loads the matching spool by itself.
